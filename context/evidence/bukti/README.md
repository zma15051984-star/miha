## ⚠️ Ограничения

1. **Это кадры видеозаписи экрана, а не исходные скриншоты.** Качество
   ниже, часть сообщений обрезана краями кадра.
2. **Даты кадров 114 и 129 в самих кадрах не видны** — требуется
   уточнение по устройству.
3. Для подачи в орган **рекомендуется повторная съёмка** этих же
   сообщений непосредственно на устройстве доверителя, с видимыми
   датой, временем и именем отправителя.
4. В чате включена **расширенная защита конфиденциальности** — экспорт
   может быть недоступен; тогда делать **непрерывную видеозапись
   прокрутки** через каждый фрагмент (см. `42-kak-dokazat...`).
